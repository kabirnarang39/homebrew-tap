# Homebrew tap for Pando

```sh
brew install kabirnarang39/tap/pando
```

Installs `pando`, `pandod` and `git-remote-pando` from the
[Pando releases](https://github.com/kabirnarang39/pando/releases). The formula is
regenerated for each release by the Pando release workflow. Pando was called Sapwood before
2.0; existing `sapwood` installs move to `pando` on `brew upgrade`.
